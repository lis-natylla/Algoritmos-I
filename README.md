# logica-e-algoritmos
Primeiro repositório de Git e GitHub
Este repositorio reune meus estudos e exercicios de logica de programacao, desenvolvidos durante minha formacao em Ciencia da Computacao na UESB.

## Objetivos

- Praticar logica de programacao e resolucao de problemas.
- Desenvolver minhas habilidades em Java e C++.
- Estudar conceitos fundamentais de algoritmos.
- Registrar minha evolucao na programacao competitiva.

## Organizacao
- `java/`: exercicios desenvolvidos em Java.
- `cpp/`: exercicios desenvolvidos em C++.
- `matematica/`: desafios envolvendo conceitos matematicos.
